# Documentation Standards

> Consistent documentation creates consistent organizations.

Documentation is organizational infrastructure.

Without shared standards, organizations cannot build shared knowledge.

The **standards/** directory defines the documentation conventions used throughout AI Business OS.

These standards ensure that knowledge remains consistent, maintainable, and understandable across Human, AI, and Hybrid Workers.

---

# Purpose

The goal of these standards is to establish a shared approach to creating and maintaining organizational knowledge.

Following common conventions makes documentation:

- Easier to read
- Easier to maintain
- Easier to automate
- Easier for AI to interpret
- Easier for organizations to scale

Consistency is an organizational capability.

---

# Standards

The documentation standards are organized into the following guides.

| Document | Purpose |
|----------|---------|
| `01_FRONT_MATTER.md` | Standard document structure and metadata. |
| `02_WRITING_STYLE.md` | Writing principles, tone, and formatting conventions. |
| `03_NAMING.md` | Naming conventions for files, directories, Workers, Playbooks, and organizational assets. |
| `04_MARKDOWN.md` | Markdown formatting guidelines and best practices. |

---

# Design Principles

Documentation within AI Business OS should be:

- Purpose-driven
- Human-readable
- AI-readable
- Consistent
- Modular
- Reusable
- Version-friendly

Good documentation is organizational infrastructure.

---

# Scope

These standards apply to every part of AI Business OS, including:

- Documentation
- Knowledge
- Playbooks
- Workers
- Examples
- Reference Organizations
- Organization Starter Kits

Contributors are encouraged to follow these standards when adding or modifying content.

---

# Philosophy

AI Business OS treats documentation as executable organizational knowledge.

Clear standards improve communication, reduce ambiguity, and enable Humans and AI to collaborate effectively.

Documentation is not merely reference material.

It is part of the operating system.
