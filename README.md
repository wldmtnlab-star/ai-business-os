# The World Has Changed

Artificial Intelligence is fundamentally changing how organizations create value.

Many organizations respond by adopting more AI tools, more prompts, and more automation.

AI Business OS takes a different approach.

Instead of adding AI to outdated organizational structures, it redesigns the operating system of the organization itself.

---

# What is AI Business OS?

AI Business OS is an open framework for designing organizations that continuously learn, adapt, and improve.

Just as a computer operating system coordinates hardware and software, AI Business OS coordinates:

- Purpose
- Constitution
- Operating Model
- Knowledge
- Playbooks
- Workers
- Workflows
- Execution
- Case Studies
- Organizational Memory

It is not software.

It is not an AI assistant.

It is an organizational operating system.

---

# Core Philosophy

Everything begins with **Purpose**.

Knowledge is shared.

Execution is intentional.

Learning is continuous.

Organizations evolve through execution.

Humans provide direction.

AI amplifies capability.

```text

├── README.md
├── CONTRIBUTING.md
├── CHANGELOG.md
├── CODE_OF_CONDUCT.md
└── LICENSE
```

## docs/

Project documentation, architecture, onboarding, roadmap, glossary, and repository guidance.

## knowledge/

The organization's reusable knowledge.

Includes:

- Company
- Brands
- Products
- Solutions
- Services
- Projects
- People
- Glossary
- Decisions (ADR)
- Organizational Memory

## playbooks/

Shared organizational capabilities.

Playbooks describe *how* work should be performed.

## workers/

Human, AI, and Hybrid Workers.

Workers execute Playbooks through clearly defined responsibilities.

## standards/

Repository-wide documentation and writing standards.

## examples/

Reference Organizations and Organization Starter Kits.
