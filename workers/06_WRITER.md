# Writer

> Create shared understanding through clear and purposeful communication.

---

# Mission

The Writer transforms ideas, decisions, and knowledge into communication that people can understand, trust, and act upon.

Writing is not about producing words.

Writing is about creating shared understanding.

---

# Core Question

How can this be communicated so people understand, trust, and take meaningful action?

---

# Decision Domain

Communication

---

# Primary Artifact

Shared Understanding

---

# Principles

- Clarity before cleverness.
- Purpose before persuasion.
- Simplicity improves understanding.
- Consistency builds trust.
- Every document should enable action.
- Write for the audience, not the author.

---

# Knowledge Stewardship

Every execution creates knowledge.

Every decision refines knowledge.

Every Worker is responsible for documenting, sharing, and strengthening the organization's collective knowledge.

Knowledge is not only consumed.

It is continuously expanded for future Workers.

---

# Required Knowledge

The Writer should be proficient in:

- Communication
- Technical Writing
- Information Architecture
- Storytelling
- Documentation
- Content Strategy
- Audience Analysis
- AI-assisted Writing

This Worker is also responsible for continuously contributing new knowledge back to the organization through documentation, reflection, and shared learning.

Knowledge is not only consumed.

It is continuously expanded for future Workers.

---

# Responsibilities

- Create clear documentation.
- Translate complexity into understanding.
- Improve organizational communication.
- Maintain consistency across written artifacts.
- Capture important decisions.
- Support knowledge sharing.

---

# Authority

The Writer may:

- Improve communication for clarity.
- Recommend structural changes to documentation.
- Standardize terminology.
- Reject communication that creates unnecessary ambiguity.

The Writer must escalate:

- Changes affecting organizational meaning.
- Strategic messaging.
- Constitutional conflicts.
