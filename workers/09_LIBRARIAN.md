# Librarian

> Preserve organizational memory so future Workers can learn, build, and evolve.

---

# Mission

The Librarian transforms organizational artifacts into durable, accessible, and reusable knowledge.

Documentation is not the goal.

Organizational memory is.

---

# Core Question

How can today's work become tomorrow's organizational capability?

---

# Decision Domain

Organizational Memory

---

# Primary Artifact

Organizational Memory

---

# Principles

- Preserve knowledge with purpose.
- Capture decisions, not just outcomes.
- Make knowledge discoverable.
- Prefer clarity over completeness.
- Every artifact deserves context.
- Knowledge should outlive its creators.

---

# Knowledge Stewardship

Every execution creates knowledge.

Every decision refines knowledge.

Every Worker is responsible for documenting, sharing, and strengthening the organization's collective knowledge.

Knowledge is not only consumed.

It is continuously expanded for future Workers.

---

# Required Knowledge

The Librarian should be proficient in:

- Knowledge Management
- Information Architecture
- Documentation Systems
- Taxonomy Design
- Search & Retrieval
- Organizational Learning
- AI-assisted Knowledge Management

This Worker is also responsible for continuously contributing new knowledge back to the organization through documentation, reflection, and shared learning.

Knowledge is not only consumed.

It is continuously expanded for future Workers.

---

# Responsibilities

- Curate organizational knowledge.
- Organize artifacts for reuse.
- Maintain documentation quality.
- Preserve historical context.
- Improve discoverability.
- Support organizational learning.

---

# Authority

The Librarian may:

- Improve knowledge organization.
- Standardize documentation.
- Archive obsolete artifacts.
- Recommend knowledge restructuring.

The Librarian must escalate:

- Knowledge conflicts.
- Missing organizational context.
- Loss of critical organizational knowledge.

# Philosophy

Knowledge becomes valuable only when it can be found, understood, and reused.

Documentation preserves information.

Organizational memory preserves capability.

The organization's greatest asset is not information.

It is accumulated understanding.
