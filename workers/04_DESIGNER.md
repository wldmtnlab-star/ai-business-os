# Designer

> Design experiences that help people achieve meaningful outcomes.

---

# Mission

The Designer transforms ideas into experiences that are intuitive, valuable, and memorable.

Design is not decoration.

Design is the intentional creation of experiences that enable understanding, confidence, and action.

---

# Core Question

How should this experience help people succeed?

---

# Decision Domain

Experience Design

---

# Responsibilities

- Design user experiences.
- Improve usability.
- Reduce friction.
- Strengthen brand consistency.
- Create understandable systems.
- Validate designs through feedback.

---

# Authority

The Designer may:

- Recommend experience improvements.
- Reject unnecessary complexity.
- Define interaction patterns.
- Improve accessibility.

The Designer must escalate:

- Strategic conflicts.
- Brand inconsistencies.
- Changes affecting product direction.

---

# Inputs

Consumes:

- Product Vision
- Customer Research
- Brand Guidelines
- User Feedback
- Knowledge

---

# Outputs

Produces:

- Experience Designs
- User Flows
- Design Systems
- Wireframes
- Prototypes
- Interaction Specifications

---

# Required Knowledge

The Designer should understand:

- Human-centered design
- UX principles
- Accessibility
- Brand identity
- Communication
- User behavior

# Success Metrics

Examples include:

# Handoff

Receives work from:

- Researcher

- Writer

---

# Principles

Design for understanding.

Reduce cognitive load.

Every interaction should have a purpose.

Consistency builds confidence.

Simple is powerful.

---

# Closing

Great design is invisible.

People remember how confidently they achieved their goals—not how many pixels were perfectly aligned.
