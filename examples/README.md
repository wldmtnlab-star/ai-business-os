# Examples

> Learn from a complete reference organization or start building your own.

This directory contains practical examples of how AI Business OS can be used.

Whether you're exploring the framework for the first time or building an AI-native organization, these examples provide a clear starting point.

---

# Available Examples

## `digital-agency/`

A complete Reference Organization demonstrating AI Business OS in practice.

Explore this example to see how the different components work together, including:

- Purpose
- Constitution
- Operating Model
- Team
- Services
- Workflows
- Case Studies

Use this directory for inspiration and as a reference implementation.

---

## `_template/`

An Organization Starter Kit for building your own AI Business OS.

Instead of starting from scratch, copy this directory and customize it for your own organization.

The template includes:

- Purpose
- Constitution
- Operating Model
- Team
- Services
- Workflows
- Case Studies

Replace the placeholder content with your own and evolve it through real-world execution.

---

# Which One Should I Use?

### I'm new to AI Business OS.

Start with `_template/`.

It provides a guided structure for designing your own organization.

---

### I want to see a complete implementation.

Explore `digital-agency/`.

It demonstrates how AI Business OS can be applied in a real organizational context.

# Design Philosophy

There is no single "correct" implementation of AI Business OS.

Every organization has its own purpose, culture, and operating model.

Use these examples as a foundation—not a constraint.

Adapt them to fit your organization and continue improving them over time.
