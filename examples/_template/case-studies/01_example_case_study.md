# Example Case Study

> Replace this document with a Case Study from a real project.

This template demonstrates how to document real-world execution using AI Business OS.

Unlike a Workflow, which describes how work is intended to be performed, a Case Study captures what actually happened, what was learned, and how the organization improved.

---

# Background

Provide context for the project.

Questions to consider:

- Who was the customer or stakeholder?
- What problem needed to be solved?
- Why was this project important?

Keep the description concise and factual.

---

# Challenge

Describe the primary challenge.

Examples:

- Technical complexity
- Tight deadlines
- Limited resources
- Organizational change
- Unclear requirements

Understanding the challenge provides context for the decisions that followed.

---

# Objectives

Describe the intended outcomes.

Questions to consider:

- What did success look like?
- What business value was expected?
- How would success be measured?

---

# Workflow Used

Reference the Workflow used to execute this project.

Example:

- `../workflows/01_example_workflow.md`

If the Workflow changed during execution, describe why.

---

# Execution Summary

Summarize how the project was executed.

Include key milestones, major decisions, and significant events.

Focus on the facts rather than a day-by-day timeline.

---

# Deliverables

List the outputs produced.

Examples:

- Documentation
- Software
- Reports
- Designs
- Training materials
- Operational improvements

---

# Outcome

Describe the results.

Examples:

- Customer outcomes
- Business impact
- Operational improvements
- Team improvements
- Technical achievements

Include measurable outcomes whenever possible.

---

# Lessons Learned

Describe what the organization learned.

Questions to consider:

- What worked well?
- What did not work?
- What surprised the team?
- What should be done differently next time?

Focus on insights that can improve future execution.

---

# Organizational Improvements

Describe how this project improved the organization.

Examples:

- Updated Workflows
- New Playbooks
- Improved Workers
- New ADRs
- Additional Organizational Memory
- Better documentation

Every completed project should strengthen organizational capability.
