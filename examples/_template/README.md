# Organization Starter Kit

> Build your own AI Business OS.

This directory provides a starting point for creating a Reference Organization using AI Business OS.

Rather than beginning with a blank directory, you can use this Starter Kit to define your organization's purpose, operating model, services, workflows, and organizational learning.

The goal is not to copy another organization.

The goal is to build one that reflects your own mission, culture, and way of working.

---

# Getting Started

We recommend completing the documents in the following order.

1. `purpose.md`
2. `constitution.md`
3. `operating-model.md`
4. `team.md`
5. `services.md`
6. `workflows/`
7. `case-studies/`

Each document builds upon the previous one.

Purpose comes first.

Execution comes later.

Learning never ends.

# How to Use This Starter Kit

1. Copy this directory.
2. Rename it to your organization.
3. Replace the placeholder content with your own.
4. Adapt the framework to fit your organization.
5. Continue improving it through real-world execution.

There is no "correct" organization.

Every organization should evolve according to its own purpose.
