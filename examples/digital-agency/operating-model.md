# Operating Model

> How MTN Digital transforms purpose into consistent execution.

The Operating Model defines the rhythms, responsibilities, and coordination mechanisms that guide how MTN Digital operates every day.

It bridges organizational principles with practical execution.

Rather than prescribing rigid procedures, it establishes repeatable patterns that help the organization learn, collaborate, and continuously improve.

---

# Operating Principles

Every activity within MTN Digital is guided by:

- Purpose First
- Human-Led. AI-Amplified.
- Knowledge Before Execution
- Evidence-Based Decisions
- Continuous Organizational Learning

These principles shape every project, decision, and interaction.

# Continuous Improvement

Continuous Evolution is embedded into everyday operations.

Every project should answer:

- What created value?
- What created friction?
- What did we learn?
- What should become organizational knowledge?
- What should change next time?

Learning is considered a deliverable.
