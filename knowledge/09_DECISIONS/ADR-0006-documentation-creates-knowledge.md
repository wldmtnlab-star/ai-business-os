# ADR-0006

# Documentation Creates Organizational Knowledge

## Context

Execution generates valuable experience, decisions, and insights.

Without documentation, this knowledge remains temporary and limited to the individuals involved.

Organizations improve when execution is transformed into shared organizational knowledge that can be reused, refined, and expanded over time.

A consistent mechanism is required to preserve learning beyond individual projects.

---

## Decision

Documentation is adopted as the mechanism for transforming execution into organizational knowledge.

Every meaningful execution should contribute reusable knowledge back to the organization.

Documentation is not considered administrative work.

It is an essential part of organizational learning.

---

## Consequences

### Positive

- Organizational knowledge continuously grows.
- Knowledge survives beyond individuals and projects.
- Future Workers can learn from previous execution.
- Better onboarding and collaboration.
- Continuous organizational improvement.

### Trade-offs

- Documentation requires time and discipline.
- Documentation standards must be maintained.
- Knowledge repositories require ongoing curation.

---

## Principle

Execution creates experience.

Documentation preserves learning.

Knowledge enables better execution.

---

Documentation preserves execution beyond the moment it happens.

Human-Led.

AI-Amplified.

Knowledge grows when learning is shared, not stored.
